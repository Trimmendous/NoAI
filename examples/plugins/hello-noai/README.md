# Hello Noai

An example Noai plugin. It shows every kind of contribution:

- **A page** (`page.html`) in the sidebar, listing your chats and jobs.
- **Commands** in the ⌘K palette (`main.js`): "Say hello" and "Count messages in this chat".
- **An event**: a notification when a job fails.
- **A theme**: Solarized, under Settings › Appearance.
- **A test agent**: "Echo" runs `cat`, so it replies with exactly what you sent.

Copy this folder, change the `id` (and the folder name to match), and build from there. See PLUGINS.md in the Noai repo for the full reference.
