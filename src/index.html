New to jobs? A quick guide for the app and the terminal

Read this guide without launching an agent or using provider allowance. Close it to skip; open it again any time.

Practice only · Built-in sample data · No agent runs

  1. Prepare your agent. Choose an installed Codex or Claude CLI, complete its sign-in in a terminal, and check the app’s Accounts page. A job uses that agent’s account and may consume its allowance.
  2. Describe a small task. Click New job, try “Summarize this project.” Choose your project folder, or leave it blank for a new folder. Keep One time for your first run. For Codex inspection tasks, choose read-only permissions.
  3. Review before starting. Create job with Run now starts real work. To practice CLI syntax safely, run this from the Noai repository:
Customize a safe CLI preview (Bash / POSIX shell)

These fields only change the command below. Nothing is submitted or saved. Leave the folder blank to preview a new project.

./bin/noai jobs create --title "First review" --prompt "Summarize this project" --project . --permissions read-only --dry-run true

The readable preview validates CLI options only; omit --format text for stable JSON. It does not connect to Noai, create a folder, check sign-in or run an agent. Remove --dry-run true --format text when ready to create the real job.

Follow the result. Open the job, select its run and use Open conversation. In a terminal, use ./bin/noai jobs list, then ./bin/noai jobs runs TASK_ID. If the CLI cannot connect, open Noai or start your already-installed user service. Fix sign-in or other reported errors before using ./bin/noai jobs retry TASK_ID for an eligible failed, paused or cancelled job.

Repeating work: Days and CLI --every 1d currently mean 86400 seconds; the local hour can shift at daylight-saving changes.
