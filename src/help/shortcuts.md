# Keyboard shortcuts

| Keys | What it does |
|---|---|
| ⌘K | Command palette: jump to a page, open a chat, run a plugin command |
| ⌘N | New chat |
| ⌘D | Split the chat to the right |
| ⇧⌘D | Split the chat downwards |
| ⌘\ | Show or hide the sidebar |
| ⌘, | Settings |
| ? or ⌘/ | Help |
| ⌘+ / ⌘− / ⌘0 | Bigger, smaller, normal text size |
| Enter | Send (Shift + Enter for a new line) |
| Esc | Close a menu; leave Settings or Help |

On Windows and Linux, use **Ctrl** instead of **⌘**.
