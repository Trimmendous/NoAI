# Getting started

Noai is a home for the coding agents on your computer, such as **Claude Code** and **Codex**. It doesn't run AI itself: it drives the agent command-line tools you already have, using your own subscriptions.

## First steps

1. **Install and sign in to an agent.** Install Claude Code or Codex and sign in once in your terminal. Noai finds them on its own; **Accounts** shows what it found.
2. **Chat.** Open **Chat**, pick a folder for the agent to work in (or keep *Automatic workspace*), and ask away.
3. **Hand off work.** In **Jobs**, ask an agent to do something now, later, or on a schedule. Jobs keep running when the window is closed.
4. **Review.** When a job works on a separate copy of your project, its changes wait in **Changes** for you to merge or throw away.

## The pages

- **Dashboard**: your plans' limits, usage over time, calls and errors.
- **Activity**: what's happening right now.
- **Chat**: talk to an agent; open several chats as tabs and split panes.
- **Jobs**: scheduled and one-off work.
- **Changes**: what jobs changed, ready for review.
- **Digest**: a short daily report on what ran and what needs you.
- **Sessions**: every past conversation, including ones started outside Noai.
- **Accounts** and **Models**: who you're signed in as, and which models each agent can use.
