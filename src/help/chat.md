# Chat

## Picking a folder

The first pill in the chat box is the folder the agent works in.

- **Automatic workspace**: each new chat gets its own fresh, empty folder. Good for questions; the agent can't see your code.
- **Choose a folder…**: work in one of your projects, so the agent can read and edit its files.
- **Recent**: your last few project folders.

A chat stays in the folder it started in. Picking another folder starts a new chat there.

## Several chats at once

- **Tabs** above the chat area are your open chats. **+** starts a new one.
- **Split panes**: the buttons at the top of a pane split it right or down. Drag a tab onto a pane's edge to split there, or onto its middle to swap it in. Drag the line between panes to resize.
- **Separate windows**: drag a tab outside the window, or use a pane's ↗ button, to open the chat in its own window. Drag that window's **Dock** handle back onto Noai to put it back.

## Finding old chats

Press **⌘K** and type part of a chat's name, or open **Sessions**, which lists every conversation.

## Permissions

Agents ask before doing anything risky. In a chat nobody is there to click "allow", so actions that need approval are refused, unless you tick **Dangerously bypass permissions**, which lets the agent run anything. Only use that in folders you'd be fine losing.
